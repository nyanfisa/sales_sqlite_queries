# Retail Sales SQL Analytics

Комплексный проект по анализу данных розничных продаж с использованием продвинутых SQL-конструкций.

---

## Описание проекта

Проект демонстрирует навыки SQL-аналитики на примере базы данных розничного магазина.  
Включает в себя полный цикл: от создания структуры БД до сложных аналитических запросов с использованием CTE, оконных функций и подзапросов.

---

## Стек технологий

- **СУБД:** SQLite 3.x
- **Инструменты:** SQLite Studio, VS Code
- **Язык:** SQL

## Схема базы данных

База данных состоит из следующих таблиц:

- `categories`  Категории товаров (вложенная структура) 
- `products`  Товары (привязка к категориям, цена) 
- `stores`  Магазины (город, адрес, статус) 
- `customers`  Клиенты (ФИО, телефон, email) 
- `sales`  Чеки/продажи (дата, магазин, клиент, способ оплаты) 
- `sale_items`  Позиции в чеке (товар, количество, цена, скидка) 
- `payment_methods`  Способы оплаты 
- `coupons`  Купоны (тип, размер скидки, статус) 
- `sale_coupons`  Применённые купоны к чекам 
- `loyalty_tiers`  Уровни лояльности (Бронза, Серебро, Золото, Платина) 
- `loyalty_accounts`  Аккаунты лояльности (номер карты, баланс баллов) 
- `loyalty_point_transactions`  Транзакции баллов (начисление, списание, сгорание) 
- `loyalty_rewards`  Награды за баллы (купон, товар, скидка на чек)

## Демонстрируемые навыки

### Базовые конструкции
-  `JOIN` (INNER, LEFT)
-  `GROUP BY` + агрегации (`SUM`, `AVG`, `COUNT`, `MAX`)
-  `HAVING` для фильтрации групп
-  Подзапросы (коррелированные и некоррелированные)

### Продвинутые конструкции
-  **CTE** (Common Table Expressions) — для повышения читаемости сложных запросов
-  **Оконные функции**:
  - `ROW_NUMBER()` — нумерация строк
  - `RANK()` и `DENSE_RANK()` — рейтингование
  - `LAG()` и `LEAD()` — доступ к соседним строкам
  - `SUM() OVER()` — накопительные итоги (running totals)
-  Аналитические запросы (первая покупка, динамика, доля в обороте)
-  Транзакции (`BEGIN`, `COMMIT`)

## Примеры запросов

- Топ-20 самых дорогих товаров  Подзапрос + `AVG` 
- Самые прибыльные категории  `JOIN` + `GROUP BY` 
- Клиенты с наибольшим количеством покупок  `JOIN` + `COUNT DISTINCT` 
- Накопительная сумма продаж по магазинам  `SUM() OVER()` 
- Изменение суммы покупки относительно предыдущей  `LAG()` 
- Рейтинг товаров по цене внутри категории  `ROW_NUMBER() OVER(PARTITION BY ...)` 
- Для каждого клиента его самая крупная покупка  CTE + `ROW_NUMBER()` 

Полный список запросов — в файле `queries.sql`.
